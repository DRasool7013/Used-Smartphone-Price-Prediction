# Used Smartphone Price Prediction

An end-to-end **Supervised Machine Learning – Regression** project that estimates the resale price of a pre-owned smartphone from the device information available in the selected dataset.

## Project objective
Build and evaluate regression models that estimate used-phone prices from attributes such as brand, operating system, RAM, storage, battery capacity, release year and usage duration (depending on which columns exist in the downloaded dataset).

**Important:** This repository does not include a third-party dataset. Download it yourself and follow its license/terms. The recommended Kaggle dataset commonly uses `normalized_used_price` as its target. A normalized value is **not automatically an INR price**. Confirm the unit and meaning from the dataset documentation before presenting currency values.

## Recommended dataset
Kaggle: [Used Phones & Tablets Pricing](https://www.kaggle.com/datasets/ahsan81/used-handheld-device-data)

Save the downloaded CSV as:

`data/used_phones.csv`

The code attempts to detect one of these target names:
- `normalized_used_price`
- `used_price`
- `selling_price`
- `resale_price`
- `price`

If the target column in your file has another name, set `TARGET_COLUMN` in `src/config.py`.

## Setup (Windows / VS Code)

Open a terminal in this project directory:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Put the dataset at `data/used_phones.csv`.

## Run all stages in order

### 1. Inspect the dataset
```bash
python -m src.data_overview
```

### 2. Clean the dataset
The overview script writes `data/used_phones_cleaned.csv` after removing exact duplicate rows and rows with missing/non-positive target values. It deliberately does not blindly fill every missing feature; imputers are fitted later on training data only.

### 3. Generate EDA charts
```bash
python -m src.eda
```

Charts are saved to `reports/figures/`.

### 4. Engineer features
```bash
python -m src.feature_engineering
```

If `release_year` exists, this stage derives `phone_age_years` using the current calendar year and drops `release_year` to avoid duplicate age inputs. The training script uses `used_phones_features.csv` when available; otherwise it falls back to the cleaned dataset.

### 5. Train, compare and tune models
```bash
python -m src.train
```

The training script:
- validates the target and removes ID/constant input columns;
- creates a holdout train/test split;
- imputes missing values and encodes categorical columns inside a scikit-learn pipeline;
- compares Linear Regression, Decision Tree, Random Forest and Gradient Boosting using cross-validation on training data;
- tunes a Random Forest using training data only;
- compares the tuned Random Forest against the best baseline model using cross-validation RMSE before choosing the final model;
- evaluates the selected final model once on the held-out test set;
- saves the fitted pipeline and metadata.

### 6. Make a terminal prediction
```bash
python -m src.predict
```

Enter the feature values when prompted. The prediction is returned in the original target column unit.

### 7. Launch the Streamlit app
```bash
streamlit run app.py
```

## Evaluation metrics
- **MAE:** average absolute error in the target's unit.
- **MSE:** average squared error.
- **RMSE:** square root of MSE, in the target's unit.
- **R²:** proportion of target variance explained; it can be negative.

Regression uses MAE/MSE/RMSE/R², not classification accuracy.

## Good analysis questions
1. Which brands occur most often in the dataset?
2. How does used price vary by brand?
3. Is price associated with phone age or days used?
4. How do RAM, internal memory and battery capacity relate to price?
5. Which features have the strongest numeric correlation with the target?
6. What limitations exist because the dataset may not include battery health, physical condition, warranty, repair history or local demand?

## Limitations and responsible use
The model estimates patterns learned from its dataset. Real resale prices can also depend on condition, battery health, warranty, repair history, accessories, seller trust, location and current market demand. If those attributes are absent, the model cannot account for them. Treat output as an estimate, not a guaranteed selling price.
